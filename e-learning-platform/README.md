# LearnHub

A frontend-only e-learning platform built with React, React Router and Context API.

## Features
Login/signup, course catalog with search and filters, enrollment, notes, videos,
practice questions, sample tests, progress tracking, profile, feedback form,
dark mode and printable certificates.

## Run locally
npm install
npm start

## Notes
There is no backend. Accounts, progress and profiles are stored in the browser
(localStorage) for demo purposes, so do not use real passwords.
